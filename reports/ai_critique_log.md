# AI Critique Log — Phase 3 (critic subagent, fresh context)
The critic was given only reports/model_card.md, reports/model_comparison.csv and reports/04_assumptions_register.csv (version 1 of the results) and attacked assumptions, leakage, units and synthetic bias. Its 20 findings (K1–K20) are logged below with my assessment and what changed. "Verified" means I checked it with code or data before deciding. Everything is SYNTHETIC.

## Genuine errors found and fixed
1. **Unfair reference (K1 + K2) — real error.** The model card compared against persistence of the *last* fuel value (P), yet the models receive `feeder_speed_pct`, which equals the fuel being fed right now. Verified: repeating the current feed (P2) gives MAE 58.5 kg/h on the test set; the first selected model C0 gave 56.0 (4 % better, not the 21 % claimed over P). Rule 3 (beat persistence by ≥5 %) would have failed. **Fix:** P2 added; rule 3 uses the better of P and P2; ablations added. After the fix the picture changed: the simplest candidate that beats P2 by a margin is the linear model L (test 53.9 vs 58.5, 7.8 %; validation 11.1 %); boosting adds nothing.
2. **Selection on the test set (K10) — real error.** Rules 2–3 used test MAE, so the test set both chose and reported. **Fix:** selection now uses validation-b MAE; test MAE only reports and feeds the safety gates (amendment A3). The outcome (L) is the same on validation and on test.
3. **Conformal calibration reused the tuning rows (K8) — real error.** Hyper-parameters and the interval half-width came from the same validation rows. **Fix:** validation split by lot into a tuning half (a) and a calibration/selection half (b) (A4). Test coverage stays 0.90–0.92 for the candidates; per-lot coverage reported (median 0.89–0.92, weakest tenth 0.80–0.86).
4. **Fragile leakage canary (K16) — real error.** The "future feature" test passed with R2 0.9951 against a 0.995 threshold (margin 0.0001), because binned boosting never reaches 1. **Fix:** the canary must lift R2 by ≥0.04 over the honest model (0.9951 vs 0.9395); truncation test (features unchanged when later rows are deleted, and when later rows are corrupted) added and reported (A6).
5. **Extended-population "ALL" mixed different rows (K15, part) — real error.** A and B were scored on 87 % of rows and the others on 100 %. **Fix:** a second ALL row on the rows that A, B and L all predict.
